# 游戏美术技法识别框架

仅从最终画面推断技术时，把结论写成“视觉证据 → 可能技术 → 置信度”，不要把推断写成源工程事实。

## 渲染管线

| 类别 | 视觉证据 | 备注 |
| --- | --- | --- |
| PBR | 金属反射、粗糙度分区、皮革/布料/皮肤对光响应不同 | 单张截图难以确认完整材质流 |
| NPR | 光照或材质响应主动偏离真实世界 | 总类，需继续判断子型 |
| Cel/Toon Shading | 明暗硬分界、2–3 层量化色阶、轮廓线 | 观察阴影边界是否随光源变化 |
| 水彩/手绘 | 湿边、纸纹、色彩渗化或可见笔触 | 区分贴图笔触与后处理叠加 |
| 厚涂/油画 | 重色块、笔触肌理、柔和体积塑造 | 可能来自概念图而非实机 |
| Pixel Art | 点阵网格、限制色板、像素级轮廓 | 注意视频缩放造成的假像素 |
| Flat/Vector | 大纯色几何块、少渐变、均匀描边 | 常见于 UI 或低复杂度场景 |
| 线描/墨线 | 强轮廓、版画或漫画式排线 | 判断是模型描边还是贴图线条 |

## 2D 绘画

| 技法 | 视觉证据 |
| --- | --- |
| 平涂/赛璐璐 | 色块边界清晰，明暗过渡极少 |
| 厚涂 | 颜色层叠、笔触可见、体积过渡自然 |
| 半厚涂 | 平涂底色加局部柔边和高光塑造 |
| 水彩 | 透明叠色、湿边、纸张纹理 |

## 3D 材质与贴图

| 技术 | 视觉证据 |
| --- | --- |
| Normal Map | 表面有凹凸光照，但轮廓和视差不变 |
| Parallax/Height | 视角变化时出现有限的深度偏移 |
| Vertex Color | 大尺度、低频的颜色或遮蔽变化 |
| Procedural Texture | 连续、无明显接缝但规律稳定 |
| Hand-painted Texture | 光影或笔触被画入颜色贴图 |
| PBR Material | Albedo、粗糙度、金属度等响应相互区分 |

## 后处理与 VFX

| 技术 | 视觉证据 |
| --- | --- |
| Bloom | 高亮区域向外溢出柔光 |
| Color Grading | 全画面稳定偏向特定色温或色相 |
| Outline | 物体边缘出现稳定线条，粗细可能随距离变化 |
| SSAO | 缝隙、接触面、转角有局部加深 |
| DOF | 焦点前后出现符合镜头距离的模糊 |
| Volumetric Light | 空气介质中可见光束或散射 |

## 判断原则

1. 同一画面可能混合多种技术，例如 PBR 材质 + NPR 光照。
2. 每项判断引用具体截图、时间戳或局部细节。
3. 视频压缩、字幕、motion blur 和后期剪辑都会降低置信度。
4. 无法排除替代解释时写“疑似/可能”，并说明需要什么额外证据。

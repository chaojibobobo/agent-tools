# 休闲化融合型 4X SLG 录屏拆解

`hybrid-slg-video-teardown` 是一个给游戏策划和制作人用的 Codex 技能。给它一段或多段竞品实机录屏，它会沿着玩家的操作还原前期体验，解释轻度玩法怎样接入基地、英雄和大世界，并给出可用于立项讨论的图文报告。

玩家第一次为什么离开前线回城？升一级总部究竟多了什么选择？如果把军营换成另一种题材，原来的供给循环还看得懂吗？这些问题都可以作为拆解重点。

## 安装

在 Codex 中发送下面这条安装请求。

> 请从 https://github.com/chaojibobobo/agent-tools/tree/main/skills/hybrid-slg-video-teardown 安装这个技能。

也可以在 macOS 或 Linux 终端克隆工具箱，再运行仓库自带的安装脚本。如果已有工具箱副本，将它更新到包含本技能的版本后，在仓库根目录运行最后一行即可。

```sh
git clone https://github.com/chaojibobobo/agent-tools.git
cd agent-tools
./scripts/install-skill.sh hybrid-slg-video-teardown
```

脚本默认安装到 `~/.codex/skills/hybrid-slg-video-teardown/`。再次运行会替换同名安装目录。

## 第一次使用

安装完成后，在下一条消息中附上可读取的录屏或文件路径。多段录屏可以像下面这样注明先后顺序，报告会保留各段自己的时间戳。

> 用 `$hybrid-slg-video-teardown` 分析这款游戏。附件 A、B、C、D 按体验顺序排列，信源只用这四段录屏。重点看第一次玩法切换、每个阶段的主次目标，以及每次升总部后新增的操作。输出带实机截图的 Markdown 报告。

如果已有目标题材，可以追加一句“评估改成海上救援是否合适，先验证哪段体验？”报告会给出 S／A／B／C 评级、机制映射和改造成本。未指定时，会评估通用适配度并列出 2–3 个候选方向。

## 报告里有什么

| 章节 | 读完能回答的问题 |
|---|---|
| 1. 一页纸立项决策卡 | 产品靠什么循环成立？最值得借鉴什么，最大短板在哪？ |
| 2. 题材包装与适配度 | 哪些动作依赖原题材？换题材时要改哪里？ |
| 3. 前期核心玩法 | 第一次玩法切换由什么触发？回去养成后，带回了什么？ |
| 4. 目标建立与引导 | 各阶段的主目标和次目标是什么？哪个事件接上下一目标？ |
| 5. 基地成长 | 每个实达等级解锁了什么？新设施何时真正投入使用？ |
| 6. 大世界沙盘定性 | 个人事件更接近《Last War》，还是联盟协作更接近《Whiteout Survival》？两者兼有时说明开放顺序，素材有限时标注“仅露入口”或“未展示”。 |
| 7. 立项借鉴与改造建议 | 先复用或改造哪一段？观察什么行为能判断是否有效？ |
| 8. 证据附录 | 哪些结论能回到原片核对？哪些环节还缺画面？ |

## 怎样读配图

- **看过程**　关键操作通常每 1–2 秒取一帧，瞬时反馈可以更密。图注标明片段、时间范围与实际间隔，方便回到原片复看。
- **看阶段变化**　相隔较远的画面标为“节点对照图”。例如，对照同一关的首次失败与养成后重试，再看中间投入了什么。
- **看基地等级**　每个可确认的实达等级单列一行，配同地标实景和等级面板或完工凭证。下一级预览单独标注，缺失的升级过程集中列入附录。

完整拆解规则和八节报告模板见 [SKILL.md](./SKILL.md)。
